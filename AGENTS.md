# Wi-Fi Explorer for Wireless@SGX

This project is built for Daniel Kam's connectivity explorer and automation portfolio. Keep source provenance and incomplete coordinate coverage explicit. Do not invent Wi-Fi coverage, operational status, seating or power availability. Preserve March 2026 catalogue membership; historical-only locations cannot enter by coordinate enrichment. All adapters must call the shared lookup engine/API, not carry different datasets. Public lookup is read-only. Never commit secrets or personal service configuration.

Use Node ES modules and node:test. Shared contract: src/catalogue.js exports lookup(operation, argumentsObject), datasetInfo(), venues(). API POST /api/lookup accepts {operation,arguments}; GET /api/venues returns {metadata,venues}. Each result has ok boolean. Core errors are {ok:false,error:{code,message},...}. Venue records have venue_id, name,address,postal_code,latitude,longitude,coordinate_source,coordinate_source_date,coordinate_precision,listed_hotspot_count,hotspots,google_maps_url. Nearest results add distance_m and google_walking_directions_url. Inputs nearest_hotspots: query OR latitude/longitude, limit (1-20), radius_m optional. search_hotspots: query, limit (1-20); get_hotspot: hotspot_id; dataset_info: empty object. Expose search_venues as query+limit (1-20), returning grouped venue records for map search. Include source dates, incomplete ranking and unlocated counts in all nearest outputs.

## Base44 dev environment

Run with `docker compose -f docker-compose.base44.yml up -d` (Node 22 slim image, source bind-mounted, `node --watch` for live reload). The dev compose uses the **public open-data edition** (`data/public-hotspots.json` + `data/public-metadata.json`) since the PDF-derived `data/hotspots.json` is gitignored and not redistributable.

The MCP SDK's `hostHeaderValidation` middleware only does exact hostname matching, which can't accept the rotating sandbox hostname. `src/http.js` uses a custom host-validation middleware instead that supports wildcard suffix patterns: entries starting with `.` (e.g. `.e2b.app`) match any hostname ending with that suffix. Exact entries behave identically to the original. `ALLOWED_HOSTS` and `ALLOWED_ORIGINS` are set from `BASE44_SANDBOX_HOST_DOMAIN` and `BASE44_PUBLIC_HOST_SUFFIX` in the dev compose so the proxy's rewritten Host header and the browser's Origin header are both accepted.

No external credentials are required to boot. `GOOGLE_MAPS_BROWSER_KEY`, `ADSENSE_CLIENT`, `ADSENSE_SLOT`, and `MCP_TOKEN` are all optional. Verify with `curl http://127.0.0.1:3000/healthz` (returns `{"ok":true,...}`).
